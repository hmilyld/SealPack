# 使用指南

## 五步向导

界面把流程切成五步，每一步只出现一件事：

```
① 主程序  →  ② 合并  →  ③ 加密  →  ④ 打包  →  ⑤ 执行
```

- **步骤条可点**：任意跳步、回看、只重跑某一步。走过的步骤有状态与实时摘要。
- **面板留在同一个工作区**：切步骤不会丢滚动位置或已展开的目录。
- **跳过是正常路径**：没勾选内容的步骤执行时自动跳过，不中断流程。
- **失败即停**：某一步失败会停下并保留日志，后续步骤不再执行。

### ① 主程序

选择要处理的 `.exe`。它所在目录会成为后面两步的扫描根目录。

- **版本号**可点「自动探测」从 exe 的版本资源读取，也可手填。
- **应用标识（AppId）**默认由主程序的产品身份推导，决定「覆盖升级」还是「全新安装」。
- **安装包口令**留空表示不加口令；它**以明文**保存在工程文件里，见[数据与安全](data-and-security.md)。
- 换主程序到另一个目录时，原先勾选的合并项会自动移除并提示。

### ② 合并

左侧是**目录树表**，右侧是**合并清单**。

| 区域 | 行为 |
| --- | --- |
| 整行（名称 / 图标 / 大小 / 状态） | 切换选中；锁定项只聚焦，不改变勾选 |
| 展开箭头 | 只展开/折叠，不改勾选 |
| 勾选框 | 只勾选/取消，目录含整棵子树 |

- 勾选 = 合并进主程序；主程序本身不在树里。
- 工具栏：搜索文件名/路径、扩展名 chips、「只看程序集」「只看已选」、展开/折叠全部、全选当前结果。打包页的「全部打包 / 全部排除」覆盖折叠目录和筛选之外的文件，锁定项除外。
- 目录显示三态（全选/部分/未选）；键盘 `↑↓→←`、`空格`、`Enter`、`Home/End`、`Ctrl+A` 可用。
- 合并后这些文件会从安装包自动排除，右侧清单会显示总数与总大小。

### ③ 加密

先选一档整体强度（**不加密 / 基础 / 标准 / 严格**），再按需微调单项。

- 开关与参数会直接生成 ConfuserEx 配置；一项保护都不启用时本步自动跳过。
- 每个选项标注了默认值与写入内容；参数项只在对应主开关开启后出现。
- 高级区的模板由 Rust 生成；手工修改后转为「手动编辑」，开关不再覆盖它。

### ④ 打包

**上半部分是打包内容**：

- 勾选 = 进入安装包；取消勾选 = 排除。
- 自动项由前两步推导，锁定且不能在这里删除：待合并程序集、主程序备份、根目录内的输出目录。
- 主程序锁定为「始终打包」。
- `*.pdb`、`docs\*` 这类通配符/文件夹规则放在右侧独立 chips，不展开成树。
- 右侧摘要显示「打包 N 个文件 · X MB」「自动排除」「自定义排除」「排除合计」与最终 `Excludes` 字符串。
- 右侧「产物」可选完整安装包 / 升级包 / 两者；选升级时下方展开只读的升级差异（基线、新增 / 修改 / 删除 / 未变）。

**下半部分是安装包选项**：

- 先选打包预设（标准发布 / 快速联调 / 最小体积 / 绿色版），再微调压缩、打包模式、加密签名、安装行为与校验清单。
- 选项按 schema 渲染，分组可折叠。

### ⑤ 执行

- **构建预检**：检查主程序、输出目录、AppId、模板占位符、工具链、.NET 运行时。有错误禁用「全部执行」，有警告先确认一次。
- **全部执行**：合并 → 加密 → 打包，过程中显示当前阶段。
- **单独执行**：只重跑某一步（例如只重跑打包）。
- **产出文件**是按钮，点一下在资源管理器中定位（不猜文件名：靠执行前后对比输出目录找出实际产出）。
- **取消构建**：运行中可中止，后端会杀掉整棵进程树；阶段状态显示「已取消」。
- **运行日志**在窗口底部，可复制、清空、保存为 txt；超过 5000 行会从最早的开始裁剪。
- **构建历史**在主程序页，保留最近 20 次；产物标签可直接定位。同一个主程序只会出现一次（合并/加密阶段会重复报告，已按路径去重）。

## 主题

只有一套 Fluent 设计，明暗三态：**自动（跟随系统）→ 深色 → 浅色**。默认自动，尊重 Windows 的「应用模式」；手动指定后不再被系统覆盖。主题保存在 `localStorage["sealpack:theme"]`。

窗口材质（Mica Alt）在 Windows 11 上启用后，标题栏 / 工程栏 / 状态栏半透明，内容区保持实色。系统开启「减弱透明度」时自动退回实色。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl` + `,` | 打开设置 |
| `Ctrl` + `W` | 关闭窗口 |
| `Alt` + `←` / `→` | 向导上一步 / 下一步 |
| `Esc` | 关闭右键菜单 / 对话框 |
| `↑` `↓` `Home` `End` | 文件树与菜单中移动焦点 |
| `→` `←` | 文件树中展开 / 折叠、进入 / 返回上层 |
| `空格` / `Enter` | 切换文件树勾选状态 |
| `Ctrl` + `A` | 全选当前可见文件 |

对话框内 `Tab` 在面板内部循环，`Enter` 触发主操作；`Esc` 与点击遮罩都会正常结束对话框。

> 全局快捷键表只 `preventDefault`、**不** `stopPropagation`：浮层需要自己处理 `Esc`。

## 右键菜单

| 位置 | 菜单项 |
| --- | --- |
| 工程行 | 打开主程序目录 / 打开输出目录 / 重新加载工程 / 复制工程名 / 重命名 / 删除工程 |
| 文件树 | 复制路径 / 在资源管理器中显示 |
| 运行日志 | 复制全部输出 / 保存日志 / 清空日志 |
| 输入框与脚本区 | 系统原生编辑菜单（剪切 / 复制 / 粘贴 / 拼写检查） |

重新加载工程会先保存当前未保存的修改，再从磁盘重读工程 JSON，并重新扫描主程序目录；在资源管理器里删了文件后用它刷新列表。重命名会打开弹窗，自动预填主程序版本信息里的 `ProductName`（拿不到就用文件名）；工程名会用于安装包名、默认安装目录和输出文件名，主程序与旧产物不会被改名。删除工程只删 `projects\<id>.json`，主程序、输出目录里的安装包、校验清单和日志都会保留。

## 产出校验清单（哈希）

打包完成后，若在选项里选了算法，会在输出目录生成校验清单，格式沿用 `sha256sum` 的 `<摘要>  <文件名>`（两个空格）。文件名按产物区分：`checksums-<算法>.txt`、`checksums-upgrade-<算法>.txt`、`checksums-both-<算法>.txt`。

```bat
certutil -hashfile 安装包.exe sha256
:: 或
sha256sum -c checksums-sha256.txt
```

清单只包含**本次构建新产生或被改写**的文件。

## 窗口

- **无边框自绘标题栏**：最小化 / 最大化 / 关闭由前端绘制，标题栏可拖拽、双击最大化。
- 无边框窗口在 Windows 上会失去系统边缘缩放，因此另用 8 个透明热区接管四边四角。
- 窗口尺寸与最大化状态会被记住，位置始终居中。

## 安装包 / 升级包

打包页右侧的「产物」决定这次出什么：

| 选择 | 产物 | 安装体验 |
| --- | --- | --- |
| 完整安装包 | `<名称>-安装包-<版本>.exe` | Inno modern 向导，可选目录 |
| 升级包 | `<名称>-升级包-<版本>.exe` | 跳过目录/任务/就绪/完成页，装到上次目录 |
| 两者 | 两个 exe | 分别如上 |

升级包的文件集**全自动**计算，不需要手工勾选：

- 基线默认取输出目录里最新的 `sealpack-manifest-<版本>.json`；也可以手动选清单或旧版本目录。
- 新增 / 修改的文件进包，删除的文件写入 `[InstallDelete]`，未变化文件不重复打包。
- 主程序有变更时一定进包；变更清单是只读的，避免漏文件。

目标机器上的校验：

- 没有检测到已安装的旧版本 → 直接中止，提示改用完整安装包。
- 已安装版本与基线版本不一致 → 弹一次确认，默认不继续。
- 安装模式（管理员 / 当前用户）必须与基线一致，否则 Inno 会把它当成另一个应用。

限制与注意：

- 升级包只支持「单文件安装包」；绿色版、分卷、关闭卸载程序的工程会被预检拦下。
- 升级包不自动启动程序；`Encryption=yes` 时仍会输入一次口令，`no` 才完全零交互，`full` 必须用 `安装包.exe /PASSWORD=口令` 启动。
- 每次成功打包都会写一份基线清单；它描述完整安装状态，不是增量。
- 校验清单按产物命名：`checksums-<算法>.txt` / `checksums-upgrade-<算法>.txt` / `checksums-both-<算法>.txt`。
