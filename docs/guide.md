# 使用指南

## 五步向导

界面把整个流程切成五步，每一步只出现一件事：

```
① 主程序  →  ② 合并  →  ③ 加密  →  ④ 打包  →  ⑤ 执行
```

- **步骤条可点** —— 任意跳步、回看、只重跑某一步。走过的步骤标成「已完成」，每步下面有一行实时摘要
  （主程序文件名 / 勾选了几个程序集 / 启用了几项保护 / 排除了几项）。
- **面板全部留在 DOM 里**，只切换显示 —— 来回翻页时滚动位置、展开的目录、正在编辑的模板都不会丢。
- **跳过是正常路径** —— 没勾选内容的步骤执行时自动跳过，不会中断流程。
- **失败即停** —— 某一步失败会停下并保留日志，后续步骤不再执行（它们依赖前一步的产物）。

### ① 主程序

选择要处理的 `.exe`。它所在目录会成为后面两步的扫描根目录（合并要合并进谁、打包要打包谁）。

- **版本号**可以点「自动探测」从 exe 的文件版本信息里读（`GetFileVersionInfo`），也可以手填。
- **安装包口令**留空表示不加口令。注意它**以明文**保存在工程文件里，见[数据与安全](data-and-security.md)。
- 换主程序时，若新主程序在**另一个目录**，原先勾选的合并项会自动移除并提示 —— 那些文件已经不在扫描范围内，
  留在列表里既看不见也取消不掉。

### ② 合并

左侧是文件树，右侧是已选文件清单。

**文件树把一行拆成三个互不干扰的点击区**，这是「点错」问题的根治：

| 区域 | 点击行为 |
| --- | --- |
| 展开箭头 | 只展开 / 折叠，**不改任何勾选** |
| 勾选框 | 只勾选 / 取消（目录含子级），**不折叠** |
| 名称 | 只把焦点移过去，**不改勾选**；双击才等于「激活」 |

找文件有三条路径，覆盖不同的心理模型：

1. **我知道大概在哪** → 直接展开目录看（树默认**不过滤**，结构完整）；
2. **我知道类型** → 点类型 chip 收敛（如只看 `.dll`）；
3. **我知道名字** → 搜索框，命中高亮、祖先自动展开，且搜索前后会记住并恢复你手工折叠的状态。

勾完再用「只看已选」复核一遍，或点「勾选当前结果」把筛选后可见的文件批量勾上。

右侧清单可筛选、可逐项 `×` 移除，也可以「全部移除」。主程序本身不会出现在树里（它不需要被合并进自己）。

**执行前会自动把主程序备份为 `<主程序名>.bakup`**，且该备份默认不进入安装包 —— 合并与加密是原地覆盖主程序，
这个备份是唯一的退路。

### ③ 加密

先选一档整体强度（**不加密 / 基础 / 标准 / 严格**），再按需微调单项。
开关与参数会直接生成 ConfuserEx 配置，一项保护都不启用时本步会被自动跳过。

每个选项的语义、默认值与它写进模板的内容见[选项参考](options.md)。

> 若你在「高级」里手工改过模板，开关就不再覆盖它。此时点预设会先问一句「是否同时用这些选项覆盖模板」，
> 想交回开关托管就点提示条上的「用当前选项覆盖模板」。

### ④ 打包

上半部分是**不参与打包的文件**：

- **自动项**由前两步推导，不能在这里删除（待合并的程序集 + 主程序备份）。界面上以只读形式展示，
  是为了让你知道「为什么这些文件没进安装包」。
- **自定义项**支持相对路径与 Inno 的通配符，用「添加文件 / 添加文件夹 / 添加通配符」三个入口管理。
  通配符不能含逗号 —— Inno 的 `Excludes` 本身以逗号分隔多项，一条里再带逗号会被拆成两条。
- 展开「写入 Excludes」可以看到最终拼出来的字符串。

下半部分是**安装包选项**：压缩格式与 LZMA 参数、打包模式、安装包加密与签名、安装行为、完整性校验。

### ⑤ 执行

三个阶段的清单，每行显示当前摘要、状态徽标、产出文件与「单独执行」按钮。

- **全部执行** —— 合并 → 加密 → 打包 顺序跑，过程中显示「正在执行 N / 3」。
- **单独执行** —— 只重跑某一步（例如只重跑打包）。
- **产出文件**是按钮，点一下在资源管理器中定位（不猜文件名：靠执行前后对比输出目录找出实际产出）。
- **运行日志**在窗口底部，stdout / stderr / 系统提示分行显示并标注来源；可复制、清空、折叠。
  超过 5000 行会从最早的开始裁剪，避免长时间构建把内存吃满。

执行期间左侧工程列表会被锁定 —— 中途切换工程会让正在跑的阶段落到另一个目标上。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl` + `,` | 打开设置 |
| `Ctrl` + `W` | 关闭窗口 |
| `Alt` + `←` / `→` | 向导上一步 / 下一步 |
| `Esc` | 关闭右键菜单 / 对话框 |
| `↑` `↓` `Home` `End` | 文件树与菜单中移动焦点 |
| `→` `←` | 文件树中展开 / 折叠、进入 / 返回上层 |
| `空格` / `Enter` | 切换文件树勾选状态 |
| `→` `←` `Home` `End` | 步骤条内切换步骤（焦点在步骤条上时） |

对话框内 `Tab` 在面板内部循环，`Enter` 触发主操作；`Esc` 与点击遮罩都会正常结束对话框，不会卡住调用方。

> 全局快捷键表只 `preventDefault`、**不** `stopPropagation`：浮层（对话框、右键菜单）需要自己处理 `Esc`，
> 全局表把它吞掉的话对话框就关不上了。

## 右键菜单

桌面程序右键一定有菜单。SealPack 用自绘菜单替掉 WebView2 的原生菜单，外观跟随当前皮肤，键盘语义完整
（`↑` `↓` 循环、`Home` / `End` 跳首尾、`Enter` 执行、`Esc` 关闭并归还焦点），贴边时自动收拢到视口内。

| 位置 | 菜单项 |
| --- | --- |
| 工程行 | 打开主程序目录 / 打开输出目录 / 删除工程 |
| 文件树 | 勾选当前结果 / 全选 / 全不选 / 清空已选与筛选 / 重新扫描目录 |
| 输入框与脚本区 | 剪切 / 复制 / 粘贴 / 全选 |
| 运行日志 | 复制全部输出 / 清空日志 |
| 主题按钮 | 窗口材质开关（Mica Alt） |

## 产出校验清单（哈希）

打包完成后，若在选项里选了算法，会在输出目录生成 `checksums-<算法>.txt`，格式沿用 `sha256sum` 的
`<摘要>  <文件名>`（两个空格），可以直接用现成工具校验：

```bat
certutil -hashfile 安装包.exe sha256
:: 或
sha256sum -c checksums-sha256.txt
```

清单只包含**本次构建新产生或被改写**的文件（比对构建前后的目录快照 + 修改时间），
不会把目录里躺着的无关文件算进去。

## 两套界面设计

标题栏的切换器上点一下即可实时切换，两套设计**共用同一份 DOM**，差异 100% 由 CSS 表达。

| 设计 | 名称 | 特征 | 手动模式下的默认主题 |
| --- | --- | --- | --- |
| 网格 | 瑞士技术网格 | Instrument Sans + JetBrains Mono；暖白纸底 `#faf8f5` + 朱红 `#d8332a`；零圆角、粗黑线、表格化控件、名录式文件树 | 浅色 |
| 终端 | 终端 · 赛博安全工具 | Chakra Petch + IBM Plex Mono；近黑底 `#05070a` + 荧光青 `#35d6e8` / 酸绿 `#a3e635`；扫描线、方括号按钮、box-drawing 文件树 | 深色 |

明暗有**三种模式**，点「主题」按钮循环：`自动（跟随系统） → 深色 → 浅色 → 自动`。

默认**自动** —— 本地程序应当尊重 Windows 的「应用模式」设置，而不是自说自话。系统明暗取自
`prefers-color-scheme`（WebView2 会把它映射到 Windows 应用模式），系统一变界面立刻跟着变，不需要重启。
一旦手动指定就不再被系统覆盖；此时**每套设计各记自己的明暗**，切回某套设计时恢复它上次用的主题。

## 窗口

- **无边框自绘标题栏**：最小化 / 最大化 / 关闭由前端绘制，标题栏可拖拽移动、双击切换最大化。
  无边框窗口在 Windows 上会失去系统提供的边缘缩放，因此另用 8 个透明热区接管四边四角。
- **窗口材质**：Windows 11 上启用 Mica Alt 后标题栏 / 侧栏 / 状态栏半透明，内容区保持实色。
  三道闸门任一不通过就完全退回实色：`set_effects()` 失败（Windows 10）、用户手动关闭（右键主题按钮）、
  系统开启「减弱透明度」。主题按钮上会出现 `▾` 表示该菜单存在。
- **窗口尺寸与最大化状态会被记住，位置不会** —— 位置始终居中，避免上次把窗口拖到已拔掉的显示器上之后找不着。
